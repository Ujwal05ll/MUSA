# 🍌 MUSA – Banana Leaf Disease Detection System

MUSA is an AI-powered web application that detects banana leaf diseases using a deep learning model.  
The system allows users (farmers/researchers) to upload an image of a banana leaf and receive disease predictions with confidence scores.

---

## 🚀 Features

- 🌿 Banana leaf disease classification
- 🤖 TensorFlow Lite model for fast inference
- 🌐 Flask REST API backend
- 🖼️ Image upload & preview
- 📊 Confidence-based predictions
- 🔗 Frontend–Backend integration using Fetch API
- 🔓 CORS enabled for smooth communication
